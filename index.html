A useful check, not a guarantee.

A matching code shows access to your shared secret, not a person’s identity. Codes can be relayed in real time, and anyone in the group can produce them. If a request involves money or feels wrong, hang up and call a number you already know. Never use or share a code from a bank, email, or other account for this check.

Your secret stays with you.

This site uses your browser’s cryptographic random generator to create a 160-bit secret. QR generation and both code checks happen locally. There are no analytics, external QR services, cookies, or browser storage. Your authenticator app may have its own backup or sync settings. If a phone or key is compromised, create a new token and have everyone replace the old one.
